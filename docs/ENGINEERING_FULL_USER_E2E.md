# Full User E2E Contract

On the exact release candidate and an approved disposable lab:

1. Start the XDR Lab operator entry point.
2. Select one representative safe scenario.
3. Run it through the documented dry-run/non-destructive path.
4. Verify evidence output and next-step guidance.
5. Exit cleanly and record candidate SHA, lab identity, path, outcome, and evidence.

Live DNS/network scenarios belong here or in release qualification, not in the fast PR gate.
